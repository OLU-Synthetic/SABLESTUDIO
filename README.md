# Sable Studio — GitHub Pages Site

Stark, minimal, luxury-coded template. Static HTML/CSS/JS.

## Quick start (GitHub Pages)
1. Create a new GitHub repo (public is easiest).
2. Upload everything in this folder to the repo root.
3. Repo → Settings → Pages → Build and deployment:
   - Source: Deploy from a branch
   - Branch: main / root
4. Your site will appear at: https://<username>.github.io/<repo>/

## What to edit first
- Replace `hello@sablestudio.example` in `contact.html` and `privacy.html`
- Replace the two case studies in `/work/` with real work + metrics
- If you want the contact form to submit:
  - Use Formspree/Basin/Netlify and set the form `action` URL in `contact.html`

## Adding images
This template uses gradients by default (fast + clean).
If you add real images, place them in `/assets/img/` and reference them from pages.
